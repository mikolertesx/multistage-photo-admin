# multistage-photo-admin

pnpm monorepo. React app in `apps/web`, shared config in `packages`.

## Prerequisites

- Node 18+ and [pnpm 9](https://pnpm.io/installation)

```bash
pnpm install
```

## Local

```bash
pnpm dev
```

## Layout

```
apps/web/                      Vite + React
packages/eslint-config/        shared ESLint config (@repo/eslint-config)
packages/typescript-config/    shared tsconfig (@repo/typescript-config)
```
